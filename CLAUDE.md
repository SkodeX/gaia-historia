# Gaia Historia

Interaktive Erdgeschichte im Browser: 3D-Globus mit Zeitregler von der Entstehung der Erde bis heute – Kontinente, Dinos, bedrohte Tiere, Reiche und Kriege.

- Antworte auf Deutsch. Rückfragen als kurze Auswahlrunden (AskUserQuestion), nicht als Fließtext.
- Bevor du den Code durchsuchst: Skill `gaia-steckbrief` laden – dort stehen Entscheidungen, Aufbau, Befehle und Phasenstand.
- Daten holen oder aufbereiten → Skill `daten-pipeline`. Im Browser prüfen → `sparsam-testen`. Shell-Befehle unter Windows → `windows-shell-fallen`.
- Nach jeder fertigen Phase den Phasenstand im Steckbrief nachtragen, damit die nächste Sitzung nichts neu erkunden muss.
